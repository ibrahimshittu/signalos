# SignalOS knowledge seed

The runtime source of truth is the versioned `SkillRegistry`. These documents are reviewer-facing
source material derived from the useful disciplines in the earlier `crypto_bot` project. They are
never inserted into the universal prompt and cannot activate themselves.

Every promoted skill must retain source references, a reviewer, an evaluation suite, an effective
date, and a signed operator decision. External content enters quarantine before it can contribute to
these documents.
